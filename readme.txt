گردونه شانس وردپرس و ووکامرس با مدیریت جایزه، احتمال، موجودی و کمپین.

== Description ==
Lucky Wheel Pro provides a Persian-first lucky wheel foundation with configurable prizes, probabilities, stock and campaign conditions.

== Installation ==
1. Upload the lucky-wheel-pro folder to /wp-content/plugins/
2. Activate the plugin.
3. Open گردونه شانس from WordPress admin.
4. Add [lucky_wheel_pro] to a page.
