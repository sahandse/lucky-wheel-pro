# گردونه شانس حرفه‌ای

افزونه گردونه شانس برای وردپرس و ووکامرس با مدیریت جوایز، احتمال برد، کمپین‌ها و رابط فارسی مینیمال.

## ویژگی‌ها
- تعریف چند جایزه
- درصد احتمال مستقل برای هر جایزه
- محدودیت موجودی جایزه
- شرط حداقل مبلغ خرید
- بازه زمانی کمپین
- دریافت شماره موبایل
- خروجی CSV
- ساختار مناسب اتصال پیامک و Elementor
- پنل مدیریتی فارسی و مینیمال
